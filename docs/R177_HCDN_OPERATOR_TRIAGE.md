## PATH B — literal `<absent>` (NOT observed in this diary)

A WebView error callback without the header does **not** prove that the CDN is innocent or that the origin/edge refused before tracking headers were injected. The header might not have been sent, might not be exposed by this callback, might have been stripped, or the 403 might have come from **either** CDN/edge or origin. Do not label this state `ORIGIN_BLOCKED`. The private draft should carry the exact UTC time, URL and status, state that the ID was not exposed, and ask the operator to inspect **both** sets of logs by time/URL (plus further metadata they request privately). A malformed value is `INVALID`, and a missing diary receipt altogether is `NO_RECEIPT`; neither is equivalent to a literal `<absent>` header. If there is no receipt, confirm the R176 build and opt-in diagnostic switch before inferring anything; respect the refusal pause.
