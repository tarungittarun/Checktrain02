# `whereismytrain.in/cache/live_status` · separate experimental web cache

**Not** `whereismytrain.org.in`, and **not** Google's Where Is My Train Android app. Source: `v2/mirror/WimtCandidate.kt`, [R62](../R62-source-audit.md), [R76](../R76-position-source-evidence.md), read-only `tools/ci/probe_wimt_position.py`. Undocumented endpoint, unconfirmed terms/permission; an answer cannot be represented as the phone app's measured position.

| Layer | Captured/parsed and used | Ignored/rejected |
| --- | --- | --- |
| Request | HTTPS GET `/cache/live_status` with `date` (dd-MM-yyyy), `train_no`, `from`, `to`, `from_day=1`, `lang=en`, fixed `appVersion` and `sb_version`; JSON Accept; manual/selected candidate only, not promoted into automatic background source. | The version values are fixed from prior research, not a proven license or recipe for phone-app parity. Do not copy/rotate app IDs or invent a client identity to obtain an undocumented API. |
| Root JSON | `start_date`, `source_station`, `destination_station`, `days_schedule`, `curStn`, root `distance`, `lastUpdateIsoDate`. Train/run/endpoints checked. A candidate `WebPoint` requires event-age and route-bracket gates; if present it is unverified and scaled on independently verified static km. | Root `lastUpdateIsoDate` is a response/cache clock, **not** movement. `distance` is not independently certified onboard GPS. Recorded distance **377.785→379.460 km in 18 seconds** while no qualifying row event changed (R76); never infer high-speed motion from this. |
| Station row | `station_code`, `source`, `departed`, `updated_at`, `actual_arrival_tm`, `actual_departure_tm`, `curStn`. Non-ETA departed rows with ordered, plausible event timestamps may generate *unverified comparison lines*, not selected official `Act`. | `source=eta` can have `actual_*` fields, and a purported departure can precede arrival or its row update. Both happened in captured runs. Future/contradictory/stale rows cannot move the glyph. The phone screenshot has at times shown different distance/time from this cache. |
| UI | Explicit `WIMT WEB · comparison only`, original candidate event and cache ages when a strict `WebPoint` exists; otherwise schedule and a rejection reason. | Never a verified NTES cell, phone-app offline/cell-tower position, or automatically refreshed `.org.in` value. |

**Request flexibility:** date/train/endpoints are actually accepted as inputs by code; no evidence that changing version numbers, `from_day`, user-agent, signatures or hidden identifiers yields a better/authorized location feed. The Google phone app's offline-onboard spotting claim cannot be assigned to this web cache or the separate `.org.in` website.
